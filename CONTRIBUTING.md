# Contributing

Agent Air Traffic Control is at an early stage. Small changes that strengthen the core coordination model are more useful than broad integrations.

## Before opening a pull request

1. Open an issue for architectural changes.
2. Keep source code, prompts, transcripts, secrets, environment variables, and command output outside shared events.
3. Add tests for protocol or collision behavior.
4. Run `pnpm check` and `pnpm test`.
5. Describe privacy and failure-mode implications.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
